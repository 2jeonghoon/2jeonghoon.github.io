  1. 2024.09 - 2026.08

    Nazgul: Adaptive SQ Management

    Graduate Researcher / Linux Kernel

    io_uring은 애플리케이션과 Linux 커널이 공유 메모리로 매핑된 큐를 통해 I/O 요청과 완료를 주고받는 비동기 I/O 인터페이스입니다.

    SQPOLL 모드에서는 커널이 애플리케이션의 I/O 요청을 폴링해 I/O 지연시간과 시스템 콜 비용을 줄입니다. 그러나 I/O 부하가 증가하면 큐가 포화되어 애플리케이션의 I/O 제출과 커널의 I/O 처리 병렬성이 저하될 수 있고, 애플리케이션은 제출 가능 여부를 확인하기 위해 큐 상태를 반복적으로 확인하며 CPU cycle을 낭비하게 됩니다.

    Nazgul은 Linux 커널에서 유효 Submission Queue 용량을 부하에 맞춰 동적으로 확장·회수하고, 애플리케이션 코드 변경 없이 요청 경로를 투명하게 리매핑합니다. 이를 통해 SQPOLL의 낮은 제출 오버헤드는 유지하면서 큐 포화로 인한 병목과 불필요한 CPU 사용을 줄였습니다.
