  1. 2024.09 - 2026.08

    Nazgul: Adaptive SQ Management

    Graduate Researcher / Linux Kernel

    io_uring은 애플리케이션과 Linux 커널이 공유 메모리로 매핑된 queue를 통해 I/O 요청과 완료를 주고받는 비동기 I/O 인터페이스입니다.

    io_uring은 SQPOLL 모드를 통해 애플리케이션의 I/O submission과 커널의 I/O issuance를 병렬적으로 수행하게 하여 I/O latency와 system call 비용을 줄입니다. 하지만 Submission Queue (SQ) depth는 정적인 크기로 생성됩니다. 작은 queue depth는 cache locality를 보존하는 대신 병렬성을 해치는 submission stall과 애플리케이션이 큐 상태를 확인함으로 인해 발생하는 CPU cycle 낭비 문제가 발생합니다. 큰 queue depth는 burst를 흡수하는 대신 cache pressure를 증가시켜 효율을 감소시킵니다.

    본 논문은 SQPOLL 모드의 io_uring에서 SQ capacity를 동적으로 관리하는 user-transparent mechanism인 Nazgul을 제안합니다. Nazgul은 기존 io_uring 인터페이스를 유지하면서도 SQ가 포화되었을 때 submission capacity를 동적으로 확장하고, 부하가 감소하면 사용되지 않는 SQ block을 회수합니다.
