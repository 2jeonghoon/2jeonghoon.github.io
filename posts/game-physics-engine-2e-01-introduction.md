Ian Millington의 2판(2010) [공개 목차](https://www.oreilly.com/library/view/game-physics-engine/9780123819765/) 순서에 따라 재구성한 개인 공부 초안이다.
책 전체 본문을 열람하여 요약한 글이 아니며, 설명과 수치 예제와 아래 학습 문제는 직접 작성했다.
원문 연습문제의 번역이나 정답을 제공하지 않는다.

예제 공통 규약은 SI 단위(m, s, kg), 오른손 좌표계, 열벡터다.
특별한 언급이 없으면 +y는 위쪽이고 시간 간격 h는 초 단위다.
정확한 연속 해, 수치 근사, 엔진의 편의적 표현을 구별해서 읽는다.

## 1.1 게임 물리란 무엇인가

게임 물리는 상태와 규칙으로 다음 순간의 움직임을 예측하는 작업이다.
위치만 그림으로 보간하는 애니메이션과 달리, 질량·속도·외력에 따라 결과가 달라진다.
현실의 모든 현상을 재현하기보다 게임에서 필요한 상호작용을 일관되게 만드는 것이 목표다.

공을 던지는 장면에서는 중력과 충돌이 중요하지만 공 내부의 분자 운동은 필요하지 않다.
모델에서 생략한 현상이 무엇인지 먼저 적어 두면 잘못된 기대를 줄일 수 있다.
입자 모델은 물체의 크기와 회전을 무시하고 질량중심의 병진 운동을 다룬다.

## 1.2 물리 엔진이란 무엇인가

엔진의 입력은 현재 상태, 외력, 접촉 정보, 시간 간격이다.
출력은 갱신된 위치와 속도이며, 게임은 이를 화면과 판정에 사용한다.
렌더링 프레임과 물리 스텝은 같은 개념이 아니다.

화면이 144번 그려져도 물리는 1/60초 간격으로 진행할 수 있다.
충돌 검출은 접촉을 찾고, 충돌 응답은 접촉을 바탕으로 운동을 바꾼다.
두 단계를 분리하면 검출 오류와 응답 오류를 따로 확인할 수 있다.

## 1.3 물리 엔진에 접근하는 방식

기존 엔진을 사용하는 방법, 간단한 전용 모델을 만드는 방법, 범용 엔진을 구현하는 방법이 있다.
자체 구현의 장점은 계산 과정과 제한을 직접 설명할 수 있다는 점이다.
상용 수준의 안정성은 적분 공식 하나보다 접촉 관리·오차 처리·도구에 많이 의존한다.

이 학습에서는 먼저 입자로 작은 문제를 해결하고 회전과 접촉으로 확장한다.
정확도, 계산 비용, 구현 복잡도는 함께 비교해야 한다.
큰 시간 간격으로 고급 공식을 쓰는 것과 작은 간격으로 단순 공식을 쓰는 것은 실험으로 비교한다.

## 1.4 물리 엔진의 수학

벡터는 방향을 포함한 양을 나타내고 미분은 시간에 따른 변화율을 나타낸다.
$v=\frac{dx}{dt}$, $a=\frac{dv}{dt}$가 위치·속도·가속도를 연결한다.
이 글의 자작 예제는 SI 단위인 m, s, kg과 오른손 좌표계를 쓴다.

3차원 벡터는 열벡터로 해석하며 +y를 위쪽으로 정한다.
$F = ma$에서 힘은 N이고 $1 \mathrm{N} = 1 \mathrm{kg}\cdot \mathrm{m}/\mathrm{s}^2$다.
픽셀 단위를 그대로 물리 단위로 사용하려면 변환 비율과 힘의 스케일까지 함께 정의해야 한다.

## 1.5 책의 소스 코드 읽기

저자의 공개 Cyclone 저장소는 책의 개념과 구현을 연결하는 1차 자료다.
한 함수를 볼 때 입력, 상태 변경, 사전 조건, 누적값 초기화를 함께 확인한다.
이 저장소의 Particle::integrate는 위치를 기존 속도로 먼저 갱신한다.

따라서 이를 반암시적 Euler 적분으로 소개하면 실제 갱신 순서를 잘못 설명하게 된다.
공개 코드의 동작과 이 노트의 자작 변형은 구분해서 기록한다.
오래된 데모의 빌드 설정과 물리 알고리즘 자체도 분리해서 읽는다.

## 1.6 책의 구성과 학습 순서

입자에서 시작해 질점 집합, 강체, 충돌 검출, 접촉 응답으로 범위를 넓힌다.
앞 단계의 상태와 수학이 뒤 단계의 입력이 되므로 순서를 지키는 편이 이해에 유리하다.
입자를 구현했다고 강체 회전이 자동으로 해결되는 것은 아니다.

회전에서는 자세·각속도·관성 텐서라는 새로운 상태와 변환이 필요하다.
각 장마다 손계산 가능한 수치 예제를 하나 남기고 결과를 비교한다.
공식의 유도와 실제 시뮬레이션 결과 사이의 차이를 별도 항목으로 기록한다.

## 덧붙인 학습 요약

모델의 가정과 계산 순서를 먼저 정하면 엔진의 결과를 설명할 수 있다.
실시간이라는 조건은 정확도뿐 아니라 일정한 계산 비용도 요구한다.

### 직접 계산해 보는 작은 예제

질량 2 kg, 위치 0 m, 속도 3 m/s인 입자에 6 N이 일정하게 작용한다고 하자.
시간 간격은 0.1 s이고 감쇠와 충돌은 없다.
가속도는 $6/2 = 3 \mathrm{m}/\mathrm{s}^2$다.

명시적 Euler 한 스텝은 $x_1 = 0 + 3\times 0.1 = 0.3 \mathrm{m}$다.
속도는 $v_1 = 3 + 3\times 0.1 = 3.3 \mathrm{m}/\mathrm{s}$다.
등가속도 해의 위치는 $0.315 \mathrm{m}$이므로 한 스텝 위치 오차는 $-0.015 \mathrm{m}$다.

## 덧붙인 자작 학습 문제

공식 목차의 연습·프로젝트 위치에 대응하는 개인 확인 과제이며 원문 문제를 재현하지 않았다.

1. **물리 60 Hz의 시간 간격은?**
   - 짧은 답: $h = 1/60\,\mathrm{s} \approx  0.016667\,\mathrm{s}$다.

2. **질량 2 kg에 6 N이 작용하면?**
   - 짧은 답: 다른 힘이 없을 때 가속도는 $3 \mathrm{m}/\mathrm{s}^2$다.

3. **회전하지 않는 불꽃은 왜 입자로 시작하는가?**
   - 짧은 답: 표현에 필요한 상태가 적고 궤적을 독립적으로 검증할 수 있기 때문이다.

### 이 장의 확인 실험

상호작용 하나를 골라 필요한 상태와 생략할 현상을 표로 적는다. 렌더링 속도와 물리 시간 간격을 각각 지정한 뒤 같은 입력을 재현하는 기준을 정한다.
