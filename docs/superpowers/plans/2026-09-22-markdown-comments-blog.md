# Markdown Publishing and Comments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish repository-managed Markdown posts through GitHub Pages, show an Agent-authorship disclosure where declared, and provide per-post GitHub Discussions comments through Giscus.

**Architecture:** A focused Node.js build library parses and validates `posts/*.md`, renders safe HTML, and generates the existing `window.BLOG_POSTS` interface plus RSS, sitemap, and a clean `_site/` artifact. The existing browser application consumes that output, renders disclosure and comment components, and degrades cleanly when Giscus has not been configured. GitHub Actions tests, builds, and deploys the static artifact.

**Tech Stack:** Node.js 20, Node built-in test runner, `gray-matter`, `markdown-it` with raw HTML disabled, vanilla JavaScript/CSS, GitHub Actions, GitHub Pages, Giscus/GitHub Discussions.

**Spec:** `docs/superpowers/specs/2026-09-22-markdown-comments-blog-design.md`

## Global Constraints

- The filename without `.md` is the immutable post slug and must match `^[a-z0-9]+(?:-[a-z0-9]+)*$`.
- Published posts require `title`, `description`, `date`, `category`, non-empty `tags`, boolean `draft`, and boolean `aiGenerated` metadata.
- Draft posts are absent from the homepage, search, category filters, direct article data, RSS, and sitemap.
- Raw HTML in Markdown is disabled.
- The exact disclosure copy is `이 글은 Agent가 제공된 정보를 기반으로 작성했습니다.`
- Giscus uses repository `2jeonghoon/2jeonghoon.github.io`, `specific` mapping, and the immutable post slug as its term.
- No secret, personal access token, or private identifier is shipped to the browser.
- The existing untracked `tmp/` directory is unrelated user content and must remain untouched.
- Existing responsive visual behavior and article query URLs (`?post=<slug>`) are preserved.

## Review Focus

- A filename containing spaces, uppercase text, `..`, or path separators must fail validation instead of producing an ambiguous URL; Task 1 pins this with invalid-slug cases.
- Raw HTML and `javascript:` Markdown links must not become executable output; Task 1 pins both cases.
- Posts sharing the same date must have deterministic filename-based ordering; Task 1 pins the tie-breaker.
- Missing Giscus IDs or a script-load failure must leave the article readable and show a useful comment status; Task 3 pins both states.
- A draft containing incomplete publication metadata must be buildable but must never leak into post data, RSS, or sitemap; Tasks 1 and 2 pin both halves.

- [ ] **Step 4: Implement the compiler's pure functions**

Create `lib/posts.mjs` with:

```js
import path from "node:path";
import matter from "gray-matter";
import MarkdownIt from "markdown-it";

const SLUG = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
const DATE = /^\d{4}-\d{2}-\d{2}$/;
const markdown = new MarkdownIt({html: false, linkify: false, typographer: false});

export function renderMarkdown(source) {
  return markdown.render(source);
}

export function calculateReadingTime(source) {
  const words = source.replace(/[`#>*_\[\]()!-]/g, " ").trim().split(/\s+/u).filter(Boolean).length;
  return `${Math.max(1, Math.ceil(words / 220))} min read`;
}

export function parsePost({filePath, source, projectRoot}) {
  const slug = path.basename(filePath, ".md");
  if (!SLUG.test(slug) || path.basename(filePath) !== `${slug}.md`) {
    throw new Error(`${filePath}: invalid slug`);
  }
  const {data, content} = matter(source);
  if (typeof data.draft !== "boolean") throw new Error(`${filePath}: draft must be boolean`);
  if (typeof data.aiGenerated !== "boolean") throw new Error(`${filePath}: aiGenerated must be boolean`);
  if (!data.draft) validatePublishedMetadata(data, filePath, projectRoot);
  return {
    slug,
    title: data.title ?? "",
    description: data.description ?? "",
    date: normalizeDate(data.date, filePath, data.draft),
    category: data.category ?? "",
    tags: data.tags ?? [],
    readingTime: data.readingTime ?? calculateReadingTime(content),
    image: data.image ?? "",
    featured: data.featured ?? false,
    draft: data.draft,
    aiGenerated: data.aiGenerated,
    content: renderMarkdown(content)
  };
}
```

Implement `normalizeDate`, `validatePublishedMetadata`, `compilePosts`, `selectFeatured`, XML escaping, `serializePosts`, `createFeedXml`, and `createSitemapXml` in the same module. `compilePosts` rejects duplicates before filtering drafts, filters drafts, then sorts by date descending and slug ascending. `serializePosts` returns `window.BLOG_POSTS = <JSON>;` with a trailing newline. Feed and sitemap URLs use `?post=<encoded slug>` and include published posts only.
